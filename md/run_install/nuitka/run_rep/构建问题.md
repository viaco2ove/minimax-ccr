## 二、发现了什么（根因）

1. **Nuitka standalone 会注入 `nuitka_module_loader` finder**，拦截了外部 `ml_lib` 里 torch/transformers 的**包内子模块动态导入**（如 `urllib.error`、`ctypes`、`importlib.util` 等），导致 `PreTrainedModel` 加载崩溃 → 模型降级
2. **移除该 finder 不可行**：会破坏 Nuitka 编译的项目包 `ccrg` 自身加载（报 `No module named 'ccrg'`）
3. **验证关键结论**：
   - diag10（移除 finder + 兜底）能成功加载 torch 2.13.0+cpu / transformers 5.15.1 / sentence_transformers 6.0.0
   - diag11（仅追加兜底、不恢复 stdlib 副本）失败——因为 `clean_old_dist` 后 **dist 丢失了全部 stdlib .py 副本**（urllib/ctypes/random 等都找不到）
